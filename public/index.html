Проверка доступности API.

{ "ok": true, "service": "submarine-dashboard" }
GET

/servers

Список серверов, общий онлайн и последние точки истории.
curl https://api.whyweloose.pw/api/submarine/v1/servers

Ответ содержит generated_at, total_online и массив servers. У каждого сервера есть id, чистое имя из MOTD в name, подпись группы group и обезличенный ключ группы group_id, а также online, last_seen, stats и history.

GET

/servers/{id}

Подробная статистика одного сервера.
curl https://api.whyweloose.pw/api/submarine/v1/servers/grief

Для неизвестного ID возвращается 404. История содержит до 360 последних измерений.

POST

/telemetry

Приём статистики от ядра Submarine.

Тело запроса JSON. Новые серверы автоматически появляются после первого отчёта; токен и регистрация не нужны. Имя сервера ядро берёт из MOTD и убирает цветовые коды Minecraft. Серверы с одного IP получают общий group_id и отображаются в группе Network.

Лимит: 120 отчётов в минуту с одного IP, максимум 256 серверов. IP используется для группы, хэшируется перед сохранением и не раскрывается в API.

curl -X POST https://api.whyweloose.pw/api/submarine/v1/telemetry \
  -H 'Content-Type: application/json' \
  --data '{"server_id":"grief","server_name":"Grief #1","stats":{"uptime_seconds":3600,"tps_current":20,"load_current_percent":12.5,"tps_average":19.98,"load_average_percent":13.2,"online":8,"max_players":100,"network_upload_kb_s":4.2,"network_download_kb_s":8.1,"thread_count":12,"memory_mb":{"main":45,"total":620,"virtual":810,"heap":48,"max":2048},"worlds":[]}}'

В stats передаются uptime, текущие и средние TPS/нагрузка, онлайн, сетевой трафик, потоки, память и массив миров. Имя можно передать в server_name, иначе берётся ID из каталога сервера. IP не сохраняется; общий IP определяет непрозрачный ключ группы.

{ "accepted": true, "server_id": "grief" }

Успешный отчёт возвращает 202; неправильный ID или JSON — 400, превышение частоты или лимита новых серверов — 429.

Поля stats

uptime_seconds, tps_current, load_current_percent, tps_average, load_average_percent, online, max_players, network_upload_kb_s, network_download_kb_s, thread_count, memory_mb, worlds.
